
Tools > Maintenance lists database and cache tools in the order below. Most clears are safe to run when something looks stale; they do not wipe settings, menus, or authorisations. Favourites and local watched history are separate.

[B]Check for Corrupt Databases[/B]
  Rebuilds any Red Light database that fails a basic integrity check. Use if menus or lists error after a crash or power loss.

[B]Clean Databases[/B]
  Removes expired rows from several caches and reports space freed. Does not wipe full caches — only stale timed-out data.

[B]Remake Settings Cache[/B]
  Rebuilds the in-memory / settings cache from settings.db. Use after odd Settings Manager behaviour; it does not reset your choices.

[B]Clear All Cache (Excluding Favorites)[/B]
  Runs most of the individual clears below in one go (including Meta, Main, Lists, service caches, scrapers, and debrid cloud caches). Does not clear Red Light Favorites. Search history is not fully covered here — use the Search History items below if needed.

[B]Clear Favorites Cache[/B]
  Clears Red Light Favorites (Movies / TV / Anime / People). Confirm carefully — this is not a temporary cache.

[B]Clear Search History Cache[/B]
  Clears Red Light search history (movies, TV, people, list searches, etc.).

[B]Clear AI Data Cache[/B]
  Clears cached Because You Watched / Similar (AI) results and related AI list rows.

[B]Clear Lists Cache[/B]
  Clears cached browse lists (for example Trakt charts and similar list payloads). Does not clear Trakt/Simkl/MDBList/PunchPlay sync databases — those have their own clears below.

[B]Clear Main Cache[/B]
  Clears the general temporary API cache (maincache.db): short-lived responses such as some debrid cloud listings, icon inventories, and other misc. TTL data. Not title metadata, not watched history, not settings.

[B]Clear Meta Cache[/B]
  Clears cached movie/TV/season title metadata from TMDb (plots, art, cast, and related info used when building lists). Does not clear Trakt, Simkl, MDBList, or PunchPlay sync/list caches — use those clears (or Clear All) for service data. After this, lists re-fetch title info as you browse (may feel slower until filled again).

[B]Clear IMDb Cache[/B]
  Clears cached IMDb-sourced data (for example parents guide / some IMDb lists).

[B]Clear MDBList / PunchPlay / Simkl / Trakt Cache[/B]
  Clears that service's Red Light sync and list cache, then typically resyncs when the account is active. Safe when not authorised (just clears local leftovers). Does not revoke authorisation.

[B]Clear TMDb Personal List Cache[/B]
  Clears cached TMDb Lists (personal) data.

[B]Clear Subtitles Cache[/B]
  Deletes temporary Red Light subtitle files from Kodi's temp folder (SubMaker / OpenSubtitles downloads used for playback and alert timing).

[B]Clear EasyNews Scrape Cache[/B]
  Clears cached EasyNews scrape/search results used during source searches.

[B]Clear EasyNews Search History[/B]
  Clears EasyNews search history only (not the scrape results cache above).

[B]Clear External Scrapers Cache[/B]
  Clears external scraper package results and related debrid hash cache used with scrapers. Does not clear Internal Scrapers.

[B]Clear Internal Scrapers Cache[/B]
  Clears EasyNews media results, Internal Scrapers torrent searches (AnimeTosho, Nyaa, Comet, StremThru Torz, Torrentio), and folder/cloud scrape helpers used in that path. Does not clear External Scrapers.

[B]Clear All Debrid / Offcloud / Premiumize / Real Debrid / TorBox Cache[/B]
  Clears that debrid's cloud/listing cache used by Red Light. Does not delete files from your debrid account. Available even when that service is not authorised.

[B]Typical use[/B]
  Stale posters/plots > Clear Meta Cache.
  Odd cloud/API leftovers > Clear Main Cache or the specific debrid clear.
  Watched ticks / service lists wrong > clear that Meta Account's cache (or Force Sync under Meta Accounts), not Meta Cache.
  Nuclear option > Clear All Cache (Excluding Favorites), then re-open lists and let them refill.
